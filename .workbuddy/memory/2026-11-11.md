# 2026-11-11

## 主题系统重构（ThemeManager / Theme.xaml / ThemePalette）

- 把 `Themes/LightTheme.xaml` + `DarkTheme.xaml` 合并为单一 `Themes/Theme.xaml`（24 个 Color、30 个 SolidColorBrush、字体/字号/Thickness/样式、主题相关 Visibility/Opacity）。`Themes/Generic.xaml` 改为第一份合并 `Theme.xaml`。
- 新增 `src/Community.Phone/Shell/ThemePalette.cs`：24 个颜色属性 + `IsDark` + `PivotUnselectedItemOpacity` + `WithAccent()` + 内置 `Dark`/`Light` 静态实例。
- 重写 `ThemeManager`：进程内唯一字典（递归扫描 Application/Window 资源树定位，缺失时才加载并插入 `MergedDictionaries[0]`）；`BrushMappings`/`ColorMappings`/`ValueMappings` 三张映射表；`ApplyThemeWithAnimation` 用 `ColorAnimation(From=当前有效色, To=目标, FillBehavior=Stop)` + `SnapshotAndReplace`，先把基础色设为目标再动画。新增 `ThemeTransitionDuration`、`EnableThemeTransitions`。
- 关键 WPF 事实（踩坑并已解决）：`Application.Resources` 及其合并字典中的 `Freezable` 会被强制冻结，`po:Freeze="False"` 无效。解决方式：首次应用时把每个冻结画刷替换为"带 1ms HoldEnd 护卫动画"的可变副本（有动画的 Freezable 不能被冻结），护卫撤销后实例保持可变并被后续动画复用。
- 已把库内/示例的主题画刷引用改为 `DynamicResource`（Theme.xaml 11 处 Style Setter、Toolkit Generic 2 处关键帧、示例 App.xaml 5 处、Settings.xaml 1 处）。
- 修复 `EmptyListHeaderStyle` 的 `Foreground` 误用 `PhoneTextMidContrastColor`（Color→Brush 类型错误）为 `PhoneTextMidContrastBrush`。
- 修复 `samples/.../Settings.xaml.cs` 缺失分号的编译错误，并补齐 RequestedTheme / AccentColor 选择器接线。
- 验证：`dotnet build` 0 error、1450 warning（与基线一致）；仓库外临时 WPF 夹具 59 项断言全通过；示例程序可正常启动。
- 文档：新增 `docs/theme-refactor.md`（改动清单、配色表、映射表、动画原理、冻结风险）。
- 已知限制：App.xaml 解析期的 `StaticResource` 捕获拿不到可变实例；`DiscreteObjectKeyFrame` 值会被冻结成快照，切主题后需重新进入状态才更新。
