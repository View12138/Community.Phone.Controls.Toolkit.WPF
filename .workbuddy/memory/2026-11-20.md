# 2026-11-20

## 投影后端重构：Viewport3D → ShaderEffect 单应变换

- 新增 `src/Community.Phone/Projection/HomographyMatrix.cs`：3×3 齐次类型，行向量约定（行=输入分量、列=输出分量），`GetOutputCoefficients(0..2)` 是取“输出分量系数”的唯一正确方式。
- `ProjectionMath` 改为 public，新增 `CreateHomography(Matrix3D, Size, depth)`、`GetPlaneDistance`、`DefaultPerspectiveDepth`。相机模型：`(0,0,depth)`、水平 FOV 由视口宽度推出，`screen = (W/2 + d·X'/(d-Z'), H/2 - d·Y'/(d-Z'))`。
- 着色器：`Projection/Rendering/Shader/PerspectiveShaderEffect.hlsl`（ps_2_0，28 条指令），`build/compile-shaders.ps1` 用 Windows SDK 的 fxc 重新生成 `.ps`，以 `Resource` 嵌入 `Community.Phone.dll`。
  - 寄存器：c0–c2 逆矩阵三个输出分量、c3 正向右量+启用、c4 输出偏移/填充尺寸、c5 元素尺寸。
  - uv 覆盖**填充后**的输出面：`position = padded + OutputBounds.xy`、`texUv = (source - xy)/zw`（曾把符号写反，症状是内容被裁掉一截）。
  - `ShaderEffect.PaddingLeft..` 是 protected，只能由派生类内部写；`UpdateShaderValue(InputProperty)` 必须调用，否则隐式输入不绑定，采样全透明。
- `ProjectionService`：`Projection` 附加属性直接作用于元素，状态放 `ConditionalWeakTable`；新增 `PreferShader`、`EffectConflictBehavior`/`EffectConflict`、`HitTestPolicy`。`EnsureProjectionHost`/`ReleaseProjectionHost` 仅作兼容。
- `ProjectionHost` 保留 API，内部改为“裁剪内容的 HostSurface + 自身着色器”；`Prefer3D` → 保持挂载，`IsRenderingIn3D` → 是否挂载。
- `TiltEffect`、`TurnstileFeatherEffect`、ListPicker 改为直接投影，不再包装；`HubTile` 保留显式 `ProjectionHost`（需要“裁剪内容、不裁剪投影结果”）。
- 默认 `ListBoxItem` 模板移除 `ProjectionHost` 部件。
- 测试：`tests/Community.Phone.Tests`（xunit，50 个）覆盖数学、服务行为、离屏渲染；`tools/ProjectionBenchmark` 可切换旧后端对比。
- 已知坑：`Style`/`ItemContainerStyle` 里共享的 `Freezable` 会被冻结、不能动画（示例改用 DataTemplate 内实例或代码创建）。
- 旧 `Viewport3D` 后端已删除；离屏对照四角误差 ≤1px、像素差异 0.4%–2%。

## 后续：删除 ProjectionHost

- 结论：`ProjectionHost` 已不是渲染必需层，只剩 `HubTile` 依赖“裁内容不裁投影”的语义，而该语义可用“外层投影元素 + 内层 `ClipToBounds` 容器”表达；`ProjectionService` 里的 `EnsureProjectionHost`/`ReleaseProjectionHost`/`GetDirectProjectionHost`/`HostInfos` 已无调用者且与“不重 Parent”冲突。
- 已删除 `src/Community.Phone/Projection/ProjectionHost.cs` 与全部包装 API；新增 `ProjectionService.PerspectiveDepth` 附加属性补回每元素相机距离。
- 迁移：`TransitionFrame` 的 presenter 改为 `ContentPresenter`（投影由页面承担，`PreferShader` 设在 presenter 的 `Content` 上）；`Panorama` 删除模板宿主与从未生效的入场投影；`ListPickerPage`/`CustomMessageBox`/示例改用附加属性；`HubTile` 改为外层投影 + 内层 `ClipToBounds`。
- 验证：临时探针（仓库外）确认转场期间页面上挂载 shader 且结束后摘除、HubTile 滑动到背面时绘制范围仍为 210×210、Panorama/ListPicker/CustomMessageBox 模板可加载、示例可启动。
- 注意：`tests/`、`tools/` 未随 `0c058d7` 提交，已不在仓库；后续如需测试需重新建立。
